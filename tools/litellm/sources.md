| How it works | Your app points the OpenAI SDK at the gateway: `client = openai.OpenAI(api_key="anything", base_url="http://0.0.0.0:4000")` then `client.chat.completions.create(model="gpt-4o", messages=[{"role": "user", "content": "Hello!"}])`. SDK form: `from litellm import completion` / `completion(model="openai/gpt-4o", messages=[...])` and `completion(model="anthropic/claude-sonnet-4-20250514", messages=[...])`, with keys from `OPENAI_API_KEY` / `ANTHROPIC_API_KEY`. | Use 1: switch models | Same `completion()` call for different providers; change the `model` string (README examples above). "Drop-in OpenAI compatibility — swap providers without rewriting your code" | README |
| Use 2: a key per team | Docs: "Give each user, team, and project a virtual key. Each key has its models, budgets, and rate limits." `/key/generate` accepts `models`, `max_budget`, `budget_duration`, `tpm_limit`, `rpm_limit`, `max_parallel_requests`, `team_id`. "After the key crosses it's `max_budget`, requests fail". Example error in the docs: `"Authentication Error, ExceededTokenBudget: Current spend for token: 7.2e-05; Max Budget for Token: 2e-07"`. "By default the `max_budget` is set to `null` and is not checked for keys." | https://docs.litellm.ai/docs/simple_proxy ; https://docs.litellm.ai/docs/proxy/virtual_keys ; https://docs.litellm.ai/docs/proxy/users |
| Use 3: stay up | Docs: "Load balancing, fallbacks, and retries move traffic between deployments when a provider has a problem." Config format: `model_list` entries (`model_name`, `litellm_params` with `model` and `api_key: os.environ/…`), then `litellm_settings: num_retries: 3 … fallbacks: [{"zephyr-beta": ["gpt-6-luna"]}] # fallback to gpt-6-luna if call fails num_retries`. Fallbacks cover errors such as 429 and 500. Router strategies include weighted pick (default), latency-based, least-busy and lowest-cost. The video shows an example config in this format with the names `main` and `backup`, labelled "example" | https://docs.litellm.ai/docs/proxy/reliability ; https://docs.litellm.ai/docs/routing |

| Catch: more than one copy | "Run Redis (7.0 or newer) as soon as you run more than one proxy instance.

| Use 1: trace every step | What a trace shows: token usage, runtime exceptions, documents retrieved by a retriever (with score and order), LLM parameters, prompt templates, tool descriptions, function calls, latency for LLMs, retrievers and other components; sessions group traces into conversations; annotations add "feedback, labels, and scores". | Use 2: grade the answers | "deterministic code-based evaluators (exact match, regex, custom heuristics)" and "LLM-as-a-judge evaluators, where a second model scores the output against a rubric"; LLM evaluators return explanations. | Catch: login off by default | "By default Phoenix deploys with authentication disabled." Roles: admin, member, viewer. In a notebook, data is not kept by default | https://arize.com/docs/phoenix/self-hosting/architecture ; https://arize.com/docs/phoenix/self-hosting/deployment-options/docker ; https://arize.com/docs/phoenix/environments |

| Catch: telemetry | "By default, Phoenix collects basic web analytics (e.g., page views, UI interactions)"; "None of your trace data, evaluation results, or any sensitive information is ever collected." Opt out with `PHOENIX_TELEMETRY_ENABLED=false` | README › Telemetry |
| Ports | 6006: "UI and OTLP HTTP collector"; 4317: OTLP gRPC collector. `phoenix serve` "will start the phoenix server on port 6006"; local traces export to `http://127.0.0.1:6006` | https://arize.com/docs/phoenix/self-hosting/deployment-options/docker ; https://arize.com/docs/phoenix/environments |
